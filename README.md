# OneDesk

One, built on the Frappe desk. One Frappe app, one module per product, enabled
per site.

Install into a bench that already carries `erpnext` and `hrms`:

    bench get-app https://github.com/yamenzak/onedesk
    bench --site <site> install-app onedesk

See `CLAUDE.md` for how code is written here.
