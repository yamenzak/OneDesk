Which app a Frappe module belongs to is read from the manifests' `owns`: the heirs map, OneStudio's forms, OneAI's tool groups and the print formats script no longer keep lists of their own (P1.5 of docs/run/RUN.md).

Which record types each app's code makes is in its manifest (`makes`); hooks.py builds one_makes_records from them.

OneCloud's folder is `one_cloud` and its module One Cloud (P2.1 of docs/run/RUN.md); this module's imports and paths into it follow. Nothing changes for people.

OneSlide is OneDeck: its folder is `one_deck` and its module One Deck (P2.2 of docs/run/RUN.md); this module's imports, paths and words naming it follow.
The points a module is held to are one list, `standard.py`, which `ready.py` reads for the points held before live and the looks (P3.2 of docs/run/RUN.md). Nothing changes for people.

OneWriter is OneDoc and OneWorkbook is OneSheet (P2.3 and P2.4 of docs/run/RUN.md); their folders and record types keep their names, `frontend/src/writer` is `frontend/src/doc`, and `one/renaming.py` moves an app's roles, `one_app` and defaults to its new name for each module's patch. Writer Document reads Document in English.

TrustCenter's folder is `trust_center` and its module Trust Center (P2.5 of docs/run/RUN.md); this module's legal.py and its imports into it follow. Nothing changes for people. `one/renaming.app_renamed` also moves the defaults keyed by a renamed folder, the tours and versions a reader has seen.

Its scripts that sat at the top of `public/js/` are in `public/js/one/` (P2.7 of docs/run/RUN.md); hooks.py, the pages that load them and the tests follow. Nothing changes for people. The Lists section's description of a module's lists is one sentence.

Nothing changes for people.
