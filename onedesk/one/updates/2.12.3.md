In OneCloud, right-click a Word, Excel, PowerPoint, OpenDocument or CSV file and choose **Open in OneOS** to edit it in a full office app in a new tab. Each save is kept as a new version of the file. Only one person edits a file in OneOS at a time: the file's row says who, and anyone else can **Make a Copy** or **View Read-Only**. Each minute OneOS is open uses OneCredits, and it closes by itself after 15 minutes without use or after 8 hours.

On the drive, a file you open in Word, Excel or LibreOffice is yours until you close it: anyone else's app opens it read-only and says it's you, and so do OneOS and the editors in OneCloud. If someone is already editing it in OneWorkbook, OneWriter or OneOS, your app opens it read-only and says who. An app that doesn't hold the file open, such as one on a phone, never saves over a newer version: your save is kept beside it as *Budget (Huda's copy).xlsx*. If someone moves a file you have open to the Recycle Bin, you're told.

In OneCloud, an Excel, CSV or Word file opens in OneWorkbook or OneWriter when they keep everything in it, and as an exact preview when they don't, so looking at a file never changes it. **Edit**, at the top of the preview and in the file's right-click menu, offers **Edit in OneWorkbook** or **Edit in OneWriter**, **Edit in OneOS** with what an hour of it costs, and **Download**. When the file has something the editor can't keep, such as comments or charts, you are told which and choose **Edit in OneOS** or **Edit Here Anyway**. A PowerPoint file offers **Make a Presentation**, a new OneSlide presentation from it, and a file with macros or an older .xls offers **Make a One Copy**.

**Edit in OneOS** opens the file in a full office app in a new tab, and each save is kept as a new version of the file. Only one person edits a file in OneOS at a time: the file's row says who, as it says who is editing it in OneWorkbook or OneWriter, and anyone else can **Make a Copy** or **View Read-Only**. Each minute OneOS is open uses OneCredits, and it closes by itself after 15 minutes without use or after 8 hours.

Changing somebody's access no longer takes away the User role of an app everybody uses, such as One. **OneCRM** users and managers now answer support issues, so a late first answer reaches them. A workspace with a second company no longer rewrites its hidden company fields on every update.
