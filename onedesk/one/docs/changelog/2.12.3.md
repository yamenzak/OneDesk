In OneCloud, right-click a Word, Excel, PowerPoint, OpenDocument or CSV file and choose **Open in OneOS** to edit it in a full office app in a new tab. Each save is kept as a new version of the file. Only one person edits a file in OneOS at a time: the file's row says who, and anyone else can **Make a Copy** or **View Read-Only**. Each minute OneOS is open uses OneCredits, and it closes by itself after 15 minutes without use or after 8 hours.

On the drive, a file you open in Word, Excel or LibreOffice is yours until you close it: anyone else's app opens it read-only and says it's you, and so do OneOS and the editors in OneCloud. If someone is already editing it in OneWorkbook, OneWriter or OneOS, your app opens it read-only and says who. An app that doesn't hold the file open, such as one on a phone, never saves over a newer version: your save is kept beside it as *Budget (Huda's copy).xlsx*. If someone moves a file you have open to the Recycle Bin, you're told.
