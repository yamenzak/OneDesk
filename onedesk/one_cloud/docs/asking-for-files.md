# Asking for Files

A file request asks people, such as a supplier, a new hire or a customer,
for files by name: *Trade licence*, *Bank letters*, *Passport*. They send
them from a link, without an account.

## Sending a Request

1. In any folder or record, choose **New › File request**.
2. Enter a title, the recipients' email addresses, and if you like a due
   date and a message.
3. Add each file you need and press **Send request**.

Each person gets their own link by email. If the workspace can't send email
yet, copy each link and send it yourself. The link opens a page listing the
files. They upload each one there, and can replace a file they got wrong.

## Each File Asked For

| Field | What it says |
| --- | --- |
| **File** | Its name, as they'll see it. What they send is saved under this name, so *Photo.jpg* rather than *IMG_4418.jpg*. |
| **Required** | Whether the request is complete without it. |
| **Multiple** | Whether they can send more than one. |
| **File Types** | Allowed types, like `pdf, jpg`. Other types are refused. Leave empty to allow any type. |
| **Saved To** | On a record, where the file goes. See below. |

## Files Saved on a Record

On a record, **Saved To** is picked from one list you can search: a file
field on it, such as an employee's *Image*, or a row of one of its tables by
kind, such as *Employee Document › Passport*. The file goes on that row,
replacing the old scan when it is a renewal, or on a new row. Leave **File**
empty and it is named after what you picked. A request that fills fields can
go to one person only.

When the file goes in a table, the sender is also asked for the row's other
plain columns, such as its number and dates. When OneAI reading is on, it
fills them from the file and the sender checks them.

## Where Files Go

| Request made from | Files go to |
| --- | --- |
| A folder | A new folder inside it, named after the request, with a folder for each person when you ask several people. |
| A record | The record, as its attachments. |
| **Requests** | A new folder in My Files. |

Someone asked who has an account here also sees each file under **Asked of
You** on One's Home, and sends it from there without the link.

## Following a Request

**Requests** lists each request and how many people have sent everything.
Open one to see what arrived and from whom. Right-click › **Progress…** shows
each person against each file, with their link to copy, **Remind** and
**Close request**. Once closed, the links no longer accept files.

You're notified as each file arrives. People who haven't finished get an
email reminder three days and one day before the due date, and on the day.
