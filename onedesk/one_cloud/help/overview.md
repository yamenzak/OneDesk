# What {one_cloud} Is

{one_cloud} holds the company's files in one place: your own files, the files
your team shares, and every file attached to a record in {one}, such as an
invoice's PDF or an employee's passport scan. It works like the file
explorer on your computer, and the files are kept in cloud storage, not on
the workspace's server.

## Finding Your Way

**{one_cloud}** in the dock opens the explorer at full width. The folder tree
on the left is how you move around, so the side panel starts closed.

| Part | What it holds |
| --- | --- |
| **The folder tree**, on the left | The places below, each opening to its folders. |
| **The heading** | The folder's name, **New**, and **Details** or **Tiles** at its other end. |
| **The list** | What is in the folder. Click a column heading to sort by it. |
| **The foot** | How full the workspace's storage is, the question mark that opens this Help, the play button that takes the tour, and {one_cloud}'s version, which opens What's New. |

## The Places

| Place | What is in it |
| --- | --- |
| **My Files** | Your own folders and files. Nobody else sees them unless you share them. |
| **Recent** | Files you opened or added lately, newest first. |
| **Starred** | Files and folders you starred (right-click › **Star**). |
| **Shared with Me** | What other people shared with you. |
| **Libraries** | Folders shared by a team, with their own members. |
| **Company** | Folders everyone in the company can open and add to. You can rename, move and delete what you added, and so can a workspace administrator. |
| **Records** | A folder for each record type that has files, such as Sales Invoice, Employee or Project, with a folder for each record inside it. You only see records you can open. |
| **Mail** | A folder for each of your mailboxes, with the files its messages sent and received. |
| **Network** | SFTP and WebDAV servers you connected. |
| **Requests** | Files you requested from people, and how far each request has come. |
| **Recycle Bin** | Deleted items, kept for 30 days. **Restore** puts an item back where it was. |
