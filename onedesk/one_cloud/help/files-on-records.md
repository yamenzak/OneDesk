# Files on Records

Every file attached to a record in {one} is in {one_cloud}, under **Records**,
and every record shows its files in a tab of its own.

## A Record's Files Tab

Every record in {one} has a **Files** tab at the end of its form, with the
number of files next to it. The tab is the explorer, opened on the record's
folder.

- Drop files in, preview, rename and share them, and ask for files with
  **New › File request** ([Asking for Files](asking-for-files)).
- Click the path to open the record's folder in {one_cloud}.
- **Files** in the side panel opens the same tab.
- The tab appears once the record is saved.

## The Records Folder

**Records** in {one_cloud} has a folder for each record type that has files,
such as Sales Invoice, Employee or Project, with a folder for each record
inside it. You only see records you can open. Dropping a file on a record's
folder attaches it to that record.

A file on a record is the record's: whoever can open the record can open the
file, and whoever can change the record can add to it.

## A Project's Folder

A project's folder also has:

| Folder | What it holds |
| --- | --- |
| **Featured Media** | The photos and videos the project is shown with. See {one_project}'s Help, A Project's Page. |
| **Tasks** | Each of its tasks that holds files, as a folder of its own. |
| A folder per sub-project | That sub-project's folder. |

The files stay attached to their own task or sub-project. Inside a record's
Files tab those folders open in place, and anything else opens {one_cloud}.

## Attaching From {one_cloud}

The upload dialog (any attach button, an image in the text editor, a
comment's attachment) has a **{one_cloud}** option next to My Device, Link and
Camera.

1. Choose **{one_cloud}**.
2. Double-click a file, or select several and press **Attach**.

The file is attached without uploading it again. A file uploaded through the
dialog that isn't attached to a record goes to your My Files.
