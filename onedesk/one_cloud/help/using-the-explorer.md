# Using the Explorer

How to move around {one_cloud}, find a file, and add, copy, move and delete
files. Changes other people make appear in the open folder without
refreshing.

## Moving Around

- **Folder tree**: click a folder to open it, or the arrow to expand it.
- **Address bar**: back, forward and up, then the current path. Click part
  of the path to go there, or click the empty space, type a path such as
  `My Files/Projects/2026` and press Enter.
- The current folder is in the page's address, so the browser's back button
  works. A link you send to someone opens the same folder for them, if they
  have access to it.

## Searching

**Search** looks in the current folder and its subfolders. **Search
everywhere** widens it to every file you can open: My Files, Company,
Shared with Me, your libraries and the files of every record you can see.
At the top level of {one_cloud} it searches everywhere by default.

Right-click a result for **Open file location**. Servers under Network
aren't searched.

## Adding Files

**New**, next to the folder's name, makes a folder, a workbook, a document
or a presentation, or uploads files or a whole folder. You can also drag
files or folders from your computer onto the page or onto a folder.

When {one_ai} is on, **New** also makes a picture, music, a short video or
speech from what you describe, saved in the folder. A picture and speech
arrive in a few seconds. Music and a video take longer, and you get a
notification when they're ready.

## Choosing and Arranging

- **Details** and **Tiles**, at the other end of the folder's name, switch
  the view. Click a column heading to sort by it.
- **Choose** files with the box at the start of each row (on Tiles, in a
  tile's corner), with Ctrl or Cmd and Shift as you click, or by dragging a
  box from an empty part of the list. The box over the list chooses all.
  What you can do with them (cut, copy, rename, share, download, delete)
  takes the place of the column headings, with how many you chose.
- **Color…** in a folder's right-click menu draws its icon in a colour, for
  everybody who sees it, in the list and the tree.
- **Preview pane**: the button at the end of the address row shows the
  selected file (images, PDFs, text, video and audio) with its size, date
  and owner. With nothing selected it shows the folder: how many folders
  and files it holds and their total size. On a phone a file opens instead.
- **Right-click** an item to open, download, copy a link, cut, copy, paste,
  rename or delete it.

## Copying and Moving

| You drag | What happens |
| --- | --- |
| Between your own folders | The item moves. Hold Ctrl to copy it instead. |
| Between a record and one of your folders | It is copied. The record keeps its file and your folder gets a copy. |
| Onto a record's folder | The file is attached to that record. |
| Between a server and your folders | It is copied. |

Two items with the same name in one folder are kept as *Report.pdf* and
*Report (2).pdf*.

## Deleting and the Recycle Bin

Deleting moves an item to the **Recycle Bin**, where it stays for 30 days.
**Restore** puts it back where it was, or in My Files if that folder is
gone too. Deleting from the Recycle Bin, or emptying it, can't be undone.

## Keyboard Shortcuts

| Key | Action |
| --- | --- |
| Enter | Open |
| Backspace | Back |
| F2 | Rename |
| Delete | Move to Recycle Bin |
| Shift+Delete | Delete permanently |
| Ctrl+A | Select all |
| Ctrl+X, Ctrl+C, Ctrl+V | Cut, copy, paste |
| Ctrl+Shift+N | New folder |
| Ctrl+F | Search |
| Ctrl+Shift+F | Search everywhere |
| F5 | Refresh |

Click, Ctrl+click and Shift+click select one item, several items or a range.
