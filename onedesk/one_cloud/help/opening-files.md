# Opening a File

Clicking a file anywhere in {one} opens it in {one}. Downloading saves it under
its own name.

## Pictures, PDFs and Video

**Open** a file (double-click, Enter, or tap on a phone) to see it over the
whole window: pictures, videos, music, PDFs, Markdown, and text or code
files. The arrows, the arrow keys or a swipe go to the next file in the
folder, and Back or Escape closes it. A file {one} can't show offers
**Download**.

**Edit** a picture (PNG, JPEG or WebP) from the button over it: crop it
freely or to a shape, turn it, flip it, straighten it, set its width, and
change its brightness, contrast and saturation. **Save** keeps the old one
as a version, and **Save as Copy** makes a new file next to it.

## Office Files

An Excel or CSV file opens in {one_sheet}, and a Word file in {one_doc},
when they keep everything in it. What is changed is saved back into the same
file, and what it held before is kept as a version. A file with something
they don't keep, such as comments or charts, opens as an exact preview
instead, so looking at it never changes it.

| File | Clicking it | **Edit** offers |
| --- | --- | --- |
| Excel (.xlsx), CSV, Word (.docx) | {one_sheet} or {one_doc}, or the preview if they would drop something | **Edit in {one_sheet}** or **Edit in {one_doc}**, **Edit in OneOS**, **Download** |
| PowerPoint (.pptx) | The preview | **Make a Presentation**, **Edit in OneOS**, **Download** |
| With macros (.xlsm, .docm), older Excel (.xls) | The preview | **Edit in OneOS**, **Download**, **Make a {one} Copy** |
| OpenDocument, older Word and PowerPoint (.doc, .ppt) | The preview | **Edit in OneOS**, **Download** |

**Edit** is at the top of the preview, and in the file's right-click menu.

- **Make a Presentation** makes a new {one_deck} presentation from the slides.
  The PowerPoint file stays as it is.
- **Make a {one} Copy** makes a workbook or document of {one}'s own from the
  file, next to it. The file stays as it is.
- **Edit in OneOS** says what an hour of it costs. See
  [Editing in OneOS](editing-in-oneos).

A file somebody is editing says so under its name, such as **Huda is
editing in {one_sheet}**.

## Previews and PDFs

A Word, Excel, PowerPoint or OpenDocument file that {one_sheet} or {one_doc}
can't show as it is opens as a PDF preview straight away, for 1 credit.
Each version of a file is turned into a PDF once, so opening it again is
free. Other files in the viewer offer **Preview**.

- **Convert to PDF** in a file's right-click menu saves the PDF next to it.
- **Combine into PDF…** puts the PDFs and pictures you chose into one new
  PDF in the folder. Drag the rows in the dialog to change their order.

## When an Editor Drops Something

{one_sheet} and {one_doc} don't keep everything an Excel or Word file can
hold. {one_sheet} keeps an Excel file's look and changes only the cells you
edit, but charts, slicers, shapes and a few more change or go. {one_doc}
drops comments, tracked changes, headers and footers and the like.
Choosing **Edit in {one_sheet}** or **Edit in {one_doc}** on such a file
first names them, such as *This file has charts and slicers {one_sheet}
can't keep.*

| Button | What it does |
| --- | --- |
| **Edit in OneOS** | Opens the file in a full office app, which keeps everything. |
| **Edit Here Anyway** | Opens it in {one_sheet} or {one_doc}. Nothing is dropped until you choose Save Over Original. |

In the editor, a bar over it names what would go, and your changes stay
there until you choose:

| Button | What it does |
| --- | --- |
| **Save Over Original** | Saves your changes into the file. What the bar names is dropped. The file as it was is kept as a version. |
| **Save as Copy** | Saves your changes as a new file next to it, and goes on in the copy. The original stays as it was. |

If a new version of the file arrives before you choose, your changes are
kept as a copy next to it, named for you, such as *Budget (Huda's copy)*.
Until you choose, clicking the file opens it in the editor with the bar.

## Files Made in {one}

| Made in | Clicking it | **Edit** offers |
| --- | --- | --- |
| {one_sheet} | {one_sheet} | **Edit in {one_sheet}**, **Edit in OneOS**, **Download as Excel** |
| {one_doc} | {one_doc} | **Edit in {one_doc}**, **Edit in OneOS**, **Download as Word** |
| {one_deck} | {one_deck} | **Edit in {one_deck}**, **Edit in OneOS**, **Download as PowerPoint** |

**New › Workbook** makes a workbook in the folder you are in. A workbook's
menu also has **Download as CSV**.

A workbook, document or presentation made in {one} and saved from Excel,
Word or PowerPoint on the drive, or in OneOS, keeps what it was as a version
first. If the file had something {one} doesn't keep, the bar says so the next
time it is opened.

> A private file opens only for you and for people who can see the record
> it's attached to. Anyone else who gets the link sees nothing. Public files,
> such as a logo on a web page or an image in an email, open for anyone.
