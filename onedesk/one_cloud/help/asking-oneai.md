# OneAI in OneCloud

The OneAI panel in OneCloud knows the open folder and the selected file.

## What You Can Ask

| Selected | Offered |
| --- | --- |
| A file | **Summarise this file**, **Who can see this?** and **Find a file…** |
| Nothing | **Find a file…** and **What is taking the space?** |

**Find a file…** starts the question "Find the file that" for you to finish,
for example "…has our trade licence in it". It searches the contents of
files, not only their names. **What is taking the space?** lists your
largest files and how full the workspace's storage is.

## What OneAI Reads

OneAI only reads files you can open, and only when you ask. It doesn't change
anything in OneCloud: sharing, moving and deleting are done in the explorer.

**Read with OneAI** on a file's menu has OneAI read that file now, file it
and act on it. A folder whose new files OneAI reads is added in One, under
**OneAI › What OneAI Reads**. Scans and photos use OneCredits. For your own
folders, the preview pane shows whether OneAI reads the folder.

## Making Files

When OneAI is on, **New** makes a picture, music, a short video or speech
from what you describe, saved in the folder you are in. See
[Using the Explorer](using-the-explorer).
