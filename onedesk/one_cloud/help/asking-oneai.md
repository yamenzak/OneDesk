# {one_ai} in {one_cloud}

The {one_ai} panel in {one_cloud} knows the open folder and the selected file.

## What You Can Ask

| Selected | Offered |
| --- | --- |
| A file | **Summarise this file**, **Who can see this?** and **Find a file…** |
| Nothing | **Find a file…** and **What is taking the space?** |

**Find a file…** starts the question "Find the file that" for you to finish,
for example "…has our trade licence in it". It searches the contents of
files, not only their names. **What is taking the space?** lists your
largest files and how full the workspace's storage is.

## What {one_ai} Reads

{one_ai} only reads files you can open, and only when you ask. It doesn't change
anything in {one_cloud}: sharing, moving and deleting are done in the explorer.

**Read with {one_ai}** on a file's menu has {one_ai} read that file now, file it
and act on it. A folder whose new files {one_ai} reads is added in {one}, under
**{one_ai} › What {one_ai} Reads**. Scans and photos use OneCredits. For your own
folders, the preview pane shows whether {one_ai} reads the folder.

## Making Files

When {one_ai} is on, **New** makes a picture, music, a short video or speech
from what you describe, saved in the folder you are in. See
[Using the Explorer](using-the-explorer).
