- OneMail has Help now. Open it from the question mark at the foot of the
  mail window, next to the version.
- Each page is about one thing you do, and the help pages no longer name
  anything only a developer would know.
- What's New lists every version on the left. Pick one to see what changed,
  and open the help pages it touched from Read More.
