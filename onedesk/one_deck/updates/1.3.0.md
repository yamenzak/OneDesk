A presentation can be any size.

- **New › Presentation** asks the size: wide like a screen, 4:3, A4 lying
  down or standing, square, standing like a phone, or your own. A template
  keeps the size it was made at unless you choose another.
- **File › Slide Size** changes it later. Everything on every slide is
  redrawn to fit, and what it was is kept in Version History; going back to
  that version puts the old size back.
- A layout added with **Add Slide** is fitted to the presentation's size.
- **Present** fits the slides to the screen whatever their shape, and a PDF
  page is the slide's own size, so an A4 presentation prints on A4.
