# Storage and File Sizes

Where the workspace's files are kept, how full the storage is, and how big a
file can be.

## Where Files Are Kept

Every file uploaded anywhere in One goes to cloud storage, whether it's
attached to an invoice, dropped in a chat or added to OneCloud. Files open
straight from cloud storage, so large files don't slow the workspace down.

Files added before cloud storage was turned on stay on the server until
they're moved, which happens by itself each night.

## How Full the Workspace Is

At the foot of OneCloud's rail are two bars, **Storage** and **Database**,
each against what the plan allows. A bar is amber from 90% and red when
over.

- Storage is measured each night, so a file added today shows tomorrow.
- The database is measured when the page opens.
- A workspace with no plan limit shows the size without a bar.

The same numbers are on **Settings › Plan**, and administrators are told by
mail at 90%.

## Largest File Size

Up to 5 GB per file, however the file arrives: the explorer, a record's
attach button, a drive or a link. The real limit is the workspace's storage.
An upload is refused when there isn't room for it.
