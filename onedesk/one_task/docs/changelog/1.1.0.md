My Tasks and the Inbox are boards now, with a column for each status: Open, Working, Pending Review and Completed. Drag a task from one column to the next as it moves on, and to Completed when it is done. Add a task in the bar above the board, with its Expected End Date if it has one, and time any task with the play button on its card. The Inbox is what is assigned to you and has no project yet.
