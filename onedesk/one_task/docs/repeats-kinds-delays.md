# Repeats, Kinds and Delays

## Repeating Tasks

**Repeat**, in a task's **⋯** menu, sets it to repeat daily, weekly, monthly
and so on. Each time, a new task is made: due on the day it repeats, open,
with its checklist unticked, and assigned to the same people, or to whoever
did it if it was done. Stop repeating from the same menu.

## Kinds of Task

**Task Type**, under **Setup**, lists the kinds of task, such as Site Visit
or Inspection, to sort and count tasks by. Set a task's kind under **Type**
on its page.

## Late Tasks

**Delayed Tasks Summary**, under **Reports**, lists the tasks you can see,
latest first, with their dates, when they were done and how many days late.
A bar on top shows how many are on track and how many delayed. Narrow it by
**Project**, **From Date** and **To Date**, **Priority** or **Status**.
