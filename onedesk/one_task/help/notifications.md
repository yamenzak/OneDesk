# What You Are Told

| Notification | When |
| --- | --- |
| **Task Given** | Someone assigns you a task, with who, the task, its due date and project. |
| **Task Done** | Someone completes a task you assigned to them, one you made, or one you were given with them. |
| **Task Ready** | The last task yours waits on is done, so it can go ahead. |
| **Pending Review** | Someone marks a task you assigned or made **Pending Review**. |
| **Sent Back** | A task you sent for review comes back without being completed. |
| **Due Date Changed** | Someone moves the due date of a task assigned to you. |
| **Task Reopened** | A task you gave or made is opened again. |
| **Task Cancelled** | A task you gave or made is cancelled. |
| **Comment on Your Task** | Someone comments on a task you were given, gave or made. |
| **Today's Tasks** | Each morning, what's due today and what's overdue, if anything. |

Each can be turned off or changed in NotificationCenter, from **Settings** at
the foot of the rail. See [Settings](settings).
