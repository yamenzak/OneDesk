# Web Search

With web search on, OneAI can look things up on the web: a new lead's
company, a supplier, what a product costs, a general question. It says where
each answer came from.

## Turning It On

Web search is off until an administrator turns it on in **TrustCenter**,
under OneAI's services, which also agrees to it for the workspace. While it
is off, OneAI answers from the workspace alone and says when it would need
the web.

## What Leaves the Workspace

Only the question OneAI searches for, through Cloudflare to Exa, never a
record, a document or a message. Each search uses credits.
