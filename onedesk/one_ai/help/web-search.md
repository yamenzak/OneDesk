# Web Search

With web search on, {one_ai} can look things up on the web: a new lead's
company, a supplier, what a product costs, a general question. It says where
each answer came from.

## Turning It On

Web search is off until an administrator turns it on in **{trust_center}**,
under {one_ai}'s services, which also agrees to it for the workspace. While it
is off, {one_ai} answers from the workspace alone and says when it would need
the web.

## What Leaves the Workspace

Only the question {one_ai} searches for, through Cloudflare to Exa, never a
record, a document or a message. Each search uses credits.
