# OnePortal scratchpad

What is known to be wrong and what is planned, kept short.

- **Links in the agreements.** The Data Processing Addendum says customers
  and suppliers are invited to sign in, not that a link opens one record to
  whoever holds it. Adding it changes the agreement, so it waits for a
  version that says so.
- **OneAI.** Nothing here is a card yet (`ai.py`): inviting and sending a
  link open the workspace to somebody outside it.
- **Not ready.** None of the fourteen points has had its look; the walk of
  the portal's screens is to come.
