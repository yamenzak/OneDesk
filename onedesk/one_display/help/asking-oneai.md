# Asking {one_ai}

{one_ai} helps make what the screens show. It never puts anything on a screen by
itself: what it makes is kept only when you keep it.

| Ask | What happens |
| --- | --- |
| **{one_ai}** in a presentation | Design a slide, make a picture or make a short video for the presentation a playlist plays. |
| **Make Music** on a music playlist | Describe the music; it is added paused, and you are told when. |
| **Write with {one_ai}** on a custom widget | Describe a widget, and its code is written for you to try. |
| **Make the Recording** on a voice ad | The ad is recorded in the voice and tone you chose. |
| Which screens are offline? | {one_ai} says which, and since when. |
| How is the queue? | {one_ai} says how many wait for each service, and who is being served. |
| Write a spoken ad about… | {one_ai} suggests a voice ad as a card; approving it keeps the ad. |

Each of these uses credits, and an administrator can turn {one_ai} off for
{one_display} in {ai_center}.

## The Screen Keeper

When a screen says it may stop working, such as its memory nearly full or
several restarts in a day, the screen keeper, {one_display}'s agent, gives
the first {one_display} manager a to-do on that screen with the reasons.
There is one a day at most, and none while one is still open. How far it
goes is set on its tab in {ai_center}.
