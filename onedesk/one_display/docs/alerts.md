# Emergency Alerts

An emergency alert puts one message over everything on every screen, reads it
aloud and keeps it there until it is ended.

1. Open **Display Screen**.
2. From the menu, choose **Send an Emergency Alert**, write the message and
   press **Send to Every Screen**.
3. To end it, choose **End the Alert** from the same menu.

Only people allowed to send one see the menu. The others who may send one
are told, so they know it is on.
