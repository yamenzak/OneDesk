A new version reaches each server within minutes of being built, and is ready there in about a minute instead of seven. A workspace someone has paid for starts building as soon as their card is accepted, and each job carries on through its steps without pausing between them.

- **Update Now** moves a workspace straight away instead of at the next quarter hour, and an update keeps it offline for about a minute.
- A server keeps its waiting workspaces ready in about a minute each instead of eight, so signups seldom wait for one.

- A paying customer now appears in **Customers**, with the deal marked **Won** and their invoice paid.
- A server's updates now bring the newest instructions it runs by, before it builds a new version.
- A new kind of error is now on the bell only, saying which workspace, which part of One and how many times. Each morning one mail, **Errors Today**, lists the kinds new since yesterday.
- **Status** now says under **Backups** when OneAdmin's config can't be copied because there is no **Config Copy Key** in **Settings**.

A server that has stopped is started again, rather than only rebooted.
