**Home** now shows the whole business: what was paid each month and what each plan brings in, signups as a funnel from started to live, workspaces, OneAI's use, servers' memory, disk and room, every service's state, new errors by day and how far the latest release has reached. Its figures along the top include what was paid this month, signups in the last 30 days, open errors and how many services are working.

**Status** shows a card for each service, as **Servers** does, with its uptime, how long it takes to answer and a bar for each of the last 30 days. Click one to see its history underneath: its last checks, each time it failed, and how it answered over a day, a week or a month. **Health Checks** has left the rail, since Status now holds them. **All Checks** opens the full list.

**Releases** shows a card for each release, with what changed, when it was built, how long the build took, how many workspaces are on it and which servers hold it.

**Servers** opens on its cards, which are now **Cards View** in the view switcher beside **List View** and **Report View**, instead of a button on the list. The list remembers the view you were last on.

**Set Up Cloudflare** now gives its token the analytics it needs to show requests per workspace, Workers and R2 under the cards. Press **Set Up Again** once to grant them. When a Workers chart is missing for want of a permission, the screen now says which one, instead of saying Cloudflare did not answer.

Once a workspace has updated, the notice of its next update leaves the bar straight away instead of the next morning.

A new workspace is no longer placed on a server that is down.

A new workspace starts in the time zone of whoever signed up for it, so its wizard offers that zone and its nightly backup and update hour fall at night where they are, rather than in India's time.

A server whose older versions nobody uses any more now makes room for new ones, instead of staying on the version it had.

**Set Up Cloudflare** now adds the mail records for the workspace mail domain and the test mail domain when they are missing, instead of taking them as present.

Archiving a workspace whose build failed no longer waits for a backup it will never have.

**Private Apps** now lists the private apps each release holds, with the title, description and icon each app gives itself, and keeps them up to date. They are no longer added by hand, and an app a workspace has a code for always stays on the list.
