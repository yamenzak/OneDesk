Every window that opens over a screen now has one of five shapes. A question puts the question first, says what will happen, and its button names the act, red when it cannot be undone. A message has a round mark, red when something went wrong. A task or a new record can fill the window with the arrows beside the cross, and a centre opens at the size you left it.
