# OneCalendar scratchpad

What is known to be wrong and what is planned, kept short.

- **Repeating events from the dialog.** New Event makes a single event; a
  repeat is set on the event's own page. A Repeats choice in the dialog would
  save the trip.
- **A repeating event can't be dragged.** Moving one occurrence would need
  frappe to split the series, which it doesn't; the event's page changes them
  all.
- **The demo ages.** Its events are dated from the day it was built, so only
  the repeating meetings show in later weeks.
