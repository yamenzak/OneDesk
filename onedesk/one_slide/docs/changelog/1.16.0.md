**Open** a PowerPoint file in **OneCloud** and it becomes a presentation
beside it, with its words, shapes, pictures, tables, backgrounds and speaker
notes, in the file's own colours. Opening the file again opens the same
presentation. A chart, SmartArt or a video stays behind, and you are told
which slides had one.
